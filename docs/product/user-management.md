# 用户管理

## 用户账号

按用户名、邮箱和状态查询账号，查看账号 ID、权限组、状态及最后登录信息。每行使用带编辑图标的「操作」下拉菜单，按权限显示修改邮箱、重置密码、设置游戏 GM、封禁／解禁和删除；敏感操作分隔显示。注册账号和批量操作位于工具栏，批量入口显示选中数量。

### 游戏 GM

拥有 `players.view` 与 `players.gm` 权限的管理员可通过「操作 → 设置游戏 GM」打开游戏权限设置。弹窗显示目标账号、当前权限组和两个选项：普通玩家（0）、游戏管理员 GM（99）。权限组来源为服务端 `conf/groups.yml`，前端副本位于 `src/data/game/accountGroups.ts`。

设置作用于账号下所有游戏角色，不改变管理后台登录身份或后台权限。保存后必须完整退出游戏并重新登录；仅换地图或继续使用现有在线会话不会更新权限。当前组未变化时禁用保存；服务端发现旧组已变化时拒绝覆盖，刷新后重新确认。

前端调用独立 `PUT /api/players/accounts/{accountId}/gm`，包含 `group_id` 和 `expected_group_id`；普通账号资料更新接口不接受 GM 权限修改。API 使用账号锁、服务器账号保护、删除隔离与审计记录，契约见 [API 账号管理](https://github.com/happyro/happyro-api/blob/main/README.md#游戏账号权限)。

### 删除账号

删除先等待下线与最终存档。若账号角色仍是未结束拍卖的卖方或买方，任务以 `active_auction` 停止，角色和拍卖数据保留；账号保持禁止登录，正常拍卖结算完成后由管理员重试删除。删除不会提前结算或直接删除拍卖。

## 游戏角色

角色列表按玩家查询等级、职业和在线状态，详情抽屉展示成长、属性、生命／魔力和位置。拥有玩家查看与游戏控制权限时，使用小号描边的「角色属性」按钮直接打开维护弹窗，保持六个 Tab：

| Tab | 能力 |
| --- | --- |
| 职业 | 查看当前职业、选择可用目标职业并转换 |
| 等级与点数 | 调整基础等级、职业等级、素质点与技能点 |
| 基础属性 | 修改 STR、AGI、VIT、INT、DEX、LUK，或重置基础属性 |
| 四转特性 | 查看和调整可读取的四转特性，或重置特性 |
| 技能 | 学满当前职业及继承技能树，或重置已学技能并返还技能点 |
| 状态恢复 | 恢复角色生命、魔力等服务端支持的状态 |

职业 ID 与职业等级分别提交。ATK、DEF、最大 HP 等派生属性由游戏服务计算，不作为普通持久化字段直接修改。离线角色可查看已保存值；提交修改时重新读取在线状态，角色不在线时拒绝执行并保留表单。

变更经结构化 Game Control 命令交给 map-server 主线程校验、重算和保存，不能通过直接更新 `char` 或 `skill` 表修改在线角色。请求包含目标和幂等键；转职、重置等操作在确认后执行。接口和命令见 [Game Control](game-control.md) 与 [命令契约](game-control-commands.md)。

## 登录日志

查询登录时间、IP、结果与失败原因。删除和导出入口不提供。

## 功能边界

角色写操作使用受权限保护的通用结构化命令入口；目前未提供按成长、属性、技能等分别授权的业务接口。技能详情、面向管理员的角色操作审计查询和高风险操作必填原因仍需完善，不将这些能力列为现有功能。
