# 用户管理

## 状态

开发中

## 子菜单

### 用户账号

- 查询：按用户名、邮箱和状态分页查询。
- 详情：查看账号 ID、用户名、邮箱、权限组、状态和最后登录信息。
- 编辑：修改邮箱等账号资料。
- 注册账号：预留入口，待确认服务端 SQL 账号表写入方案后开放。
- 重置密码：设置新密码并记录审计日志。
- 封禁/解禁：切换账号状态并记录审计日志。

### 游戏角色

- 查询指定玩家的角色、等级、职业和在线状态。
- 详情和角色操作按钮待确认角色库字段及安全边界后开放。

### 登录日志

- 查询玩家登录时间、IP、结果和失败原因。
- 查看单条登录记录；删除和导出按钮暂不提供。

## 实现记录

- 已完成用户账号列表 API、状态筛选、资料更新、密码重置和封禁/解禁接口。
- 已完成前端用户账号菜单、详情抽屉、密码重置弹窗和操作入口。
- 玩家账号通过 `game` 数据库连接访问，默认读取 `login` 表；当前服务端配置为文件数据库，接口需配置 SQL 数据源后使用。
