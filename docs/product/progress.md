## 实施顺序

1. 定义私有 Game Control API、结构化命令、幂等和执行状态模型，并完成 rAthena 领域函数映射。（已完成）
2. 完成角色详情只读数据和角色维护权限入口。（已完成）
3. 实现角色成长、基础属性、状态恢复和技能重置。（已完成并通过在线角色验收）
4. 实现魔物在在线测试角色附近召唤及自动清理。（已完成并通过在线角色验收）
5. 建立游戏参数注册表和配置版本表，实现经验与掉落倍率。（已完成）
6. 完成配置回读、失败回滚及真实 map-server 集成验收。（配置回读、失败回滚、在线角色操作和测试环境通道均已完成）

每一步都必须先完成 Service、Contract 和单元测试，再接入 HTTP API 与前端；涉及 map-server 的能力还必须通过 Game Control 契约测试和真实服务验收。
