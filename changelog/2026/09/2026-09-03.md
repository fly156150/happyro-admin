# 2026-09-03

## Added

- `[backend]` 增加持久化游戏资料全局版本设置、管理权限、校验接口和设置变更审计。
- `[frontend]` 增加系统设置中的游戏资料版本配置页面。
- `[backend]` 增加双语魔物快照、MariaDB 幂等导入、组合索引、查询详情接口和本地精灵图片服务。
- `[frontend]` 增加支持名称、种族、属性、体型和首领筛选的魔物图鉴及能力、掉落详情。
- `[backend]` 增加物品武器类型投影、组合索引和筛选接口。
- `[frontend]` 增加物品图鉴仅在选择武器时显示的武器类型联动筛选和双语名称映射。
- `[backend]` 增加 Game Control 命令 DTO、幂等状态机、持久化仓储和认证 HTTP Gateway。
- `[backend]` 增加角色详情只读接口，返回成长、属性、状态、位置和在线信息。
- `[frontend]` 增加角色详情抽屉和角色维护弹窗，支持等级、职业、属性、技能及状态操作。
- `[frontend]` 在魔物图鉴增加按在线角色定位的限时召唤入口。
- `[backend/frontend]` 增加经验与掉落倍率注册表、版本记录、应用回读、失败回滚 API 和设置页面。

## Changed

- `[backend]` 统一由可注入的全局设置仓储为图鉴和物品发放选择客户端、服务端版本。
- `[frontend]` 从物品和魔物图鉴移除版本选择项，并统一限制魔物缩略图尺寸以保持表格行高稳定。
- `[frontend]` 将物品类型中的“其它”固定排列在选项末尾。
- `[frontend]` 在发放物品界面增加物品图片预览和主题自适应默认图，并在大图不可用时回退到图标。
- `[backend]` 将倍率变更限制在系统设置用例，并通过 Game Control 应用到 map-server 后回读实际值。

## Fixed

- `[backend]` 根据 GRF 解压清单解析物品图片真实路径，修复 Linux 环境下官方资源名大小写不一致导致的缺图。
- `[backend]` 支持 GRF CP949 乱码路径，补齐 7 个客户端物品图片资源。
- `[backend/frontend]` 保证无字段角色命令始终发送 JSON 对象，并保留游戏服务的可预期错误码。
- `[frontend]` 为不支持 `crypto.randomUUID` 的浏览器增加幂等键生成实现。
- `[backend]` 按注册表校验各倍率上限，并在配置写入失败时将草稿版本标记为失败。
- `[backend]` 禁止通用运营命令入口绕过系统设置直接修改战斗倍率。
