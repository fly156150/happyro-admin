# 2026-09-08

## Added

- 为游戏内冒险工具提供基于游戏 Web Token、账号、在线角色归属校验的角色维护和游戏设置 API。
- 游戏设置增加“角色维护开放范围”和“游戏设置开放范围”，均支持“所有人 / 管理员”，默认所有人。

## Changed

- Game Control 命令和设置修订支持记录发起操作的游戏账号，后台管理员与游戏账号审计身份彼此独立。
- 角色维护操作固定作用于当前登录角色，设置更新继续使用持久化、实时应用、回读校验和失败回滚流程。
- 游戏内游戏设置不再暴露角色维护和游戏设置权限治理字段；治理开关仅由管理后台修改，并按已认证游戏账号独立限流。

## Fixed

- 修复 Game Control battle-config 响应格式异常导致游戏规则页面加载失败的问题。
